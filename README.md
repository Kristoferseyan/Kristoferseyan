hey, I'm Sean. I build the things I wish existed, then run them on a mini PC under my desk. I made all of it myself (with Claude. Mostly Claude. Yup, all Claude).

- **[Jarvis](https://github.com/Kristoferseyan/jarvis)**: say "Hey Jarvis" and my Mac answers out loud. It checks my server, sets reminders and alarms, and asks before it changes anything.<br><sub>*because Siri AI is too weak. I need access to everything, everywhere, anywhere.*</sub>
- **[ServerMon](https://github.com/Kristoferseyan/servermon)**: menu bar and Apple Watch app for my homeserver. It runs a security sweep every night and explains it in plain English.<br><sub>*because I don't know the Linux commands for any of this, and I'm lazy*</sub>
- **[Gastos](https://github.com/Kristoferseyan/gastos)**: paste a receipt and it logs every line, or just ask it how much I spent on food this month.<br><sub>*not a basic budget tracker, but a basic AI budget tracker, minus sending it to anyone's database*</sub>
- **[Brownout](https://github.com/Kristoferseyan/brownout)**: reads the power company's outage posters with AI and pings my phone the night before my area goes dark.<br><sub>*neat*</sub>
- **Seanify**: my own native Spotify client for macOS, with synced lyrics. Forked from Spotifly and made it mine.<br><sub>*because Spotify has too much bloat*</sub>
- **[Bridge](https://github.com/Kristoferseyan/bridge)**: multiple Claude accounts in multiple containers inside multiple tmux windows, and one chat on my phone for all of them.<br><sub>*WFH setup pro max*</sub>

All of it runs on my homeserver. Sick ass homeserver. It runs my stuff without private businesses getting my info, and the code is all public now (except Seanify, Spotify would not like that).
